# SourceGit portable customization

Upstream: https://github.com/sourcegit-scm/sourcegit

Pinned upstream commit: c0f40a2e78d81a7474628847727644fc0c56f558 (master, retrieved 2026-11-02).
AvaloniaEdit submodule: https://github.com/love-linger/AvaloniaEdit, ddf00a91dc0da29b85c79b85c9583860213a99ff.
The GitHub source archive was imported into a local checkpoint repository after network interruptions prevented cloning. The local import commit is not the upstream commit. Tag `upstream-c0f40a2` preserves the unmodified source and pinned submodule contents.

Requirements: retain SourceGit functionality; SourceTree-style layout and palette; Windows x64 portable, no application login; repository-scoped remote credentials with automatic prompts; OpenSSH for SSH and OpenSSL for HTTPS; MCP server for AI control of the GUI (no MCP client).

Checkpoints and verification records are maintained in this repository and the sibling output directory. SourceGit and dependency license notices must accompany distributions. The UI uses SourceGit's own icons and code; no Atlassian binary assets are included.
