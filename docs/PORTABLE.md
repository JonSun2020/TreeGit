# TreeGit Windows 便携版

完整解压后双击 `TreeGit.exe`，无需安装 .NET，也无需登录 TreeGit 账号。

1. 自动使用电脑上已有且可用的 Git；未安装、路径失效或版本不兼容时，自动使用随包 `git/` 内的便携 Git。无需另行安装、联网下载或设置系统 PATH。请完整解压，保留整个 `git/` 目录。
2. 通过“文件”打开或克隆仓库。需要权限时会出现正常认证窗口；不同仓库的 HTTPS 账号可以独立保存。SSH 密钥按远程配置。
3. 主题提供“跟随系统”、**Light**、**Dark**、**Blue**。选择“跟随系统”后，系统浅色时使用 Light、系统深色时使用 Dark，并随系统切换；配置和 MCP 中对应 `Default`。初次启动仍默认为 Light，升级保留现有选择。Light 顶栏为已确认的深绿色 `#16836D`，Dark 顶栏为深灰色 `#1F1F1F`，Blue 保留蓝白配色。
4. 图谱顶部的“未提交的更改”打开下方暂存、未暂存文件及差异。顶部“提交”按钮进入完整提交编辑视图。单击左栏分支先回到日志 / 历史，保留图谱显示方式；双击当前本地分支不切换，其他本地分支先显示“切换本地分支”确认框，远程分支显示“检出远程分支”。
5. 拖动历史表头之间的边界可调整图谱、描述、日期、作者及提交列宽，设置按仓库保存。文件列表和差异区之间也可拖动；较窄的文件框内，操作按钮会自动换行。
6. 在“工具 → MCP · AI 连接”复制当前实际路径的配置。默认完整读写，AI 可执行全部 Git 操作；需要限制写入时勾选只读连接。随包的 JSON 是路径模板，使用前需替换 `C:\Tools\TreeGit\TreeGit.exe`，更推荐直接从软件复制。详细能力见 `MCP-使用说明.md`。

启动时优先恢复上次选中的仓库，其余仓库先保留标签，再逐步加载；点击尚未加载的标签会优先加载该仓库。后台完成加载不会改变当前选中的标签。外部编辑器发现和字体列表按需加载。

外观配置中的“界面字体”和“代码 / Diff 字体”均可从本机字体列表选择。首项显示当前默认字体，选择它可恢复默认；界面默认使用 Segoe UI / 微软雅黑回退，代码默认使用内置 JetBrains Mono。代码字体建议选择等宽字体，例如 Consolas。

偏好及缓存位于程序旁边的 `data/`。已保存密码在当前 Windows 用户的系统凭据库中，不随便携目录一起复制。

在“帮助 → 检查更新”下载新版本，完成后点击“重启完成更新”。勾选“启动时检测软件更新”后，每次启动自动检测，发现新版本时提示；无更新或暂时无法连接时不打扰。

下载支持取消和续传。选择“后台更新”后可以继续使用仓库，下载完成或失败时会再次显示窗口；点击更新窗口右上角的关闭按钮可选择“取消更新”或“后台更新”。也可以先选“稍后”，下次重新打开检查更新时继续。正在执行仓库操作，或还有未处理的设置、操作窗口时，会提示先完成或关闭。程序会保存设置、替换文件并重新打开，个人配置、仓库、日志及自定义 MCP 配置保留；新版无法启动时自动恢复上一版。AI 连接会暂时断开，更新后可重新连接。

连接失败、磁盘空间不足或没有写入权限时，窗口会给出对应处理方式，并提供重试和手动下载。手动升级请先退出 TreeGit，保留原 `data/` 和自定义配置，再替换程序文件。2026.23.10 及更早版本需先手动升级一次，之后即可使用自动更新。

项目及更新：https://github.com/JonSun2020/TreeGit

基于 SourceGit 2026.24，保留原版权及 MIT 许可证；界面、品牌及 MCP 为 TreeGit 的改动。内置 Git、LFS、Git Flow 和配套组件遵循各自许可证，见 `git/COMPONENTS.md`。当前主要验证平台为 Windows x64。

二进制文件变更直接显示左右十六进制 / ASCII 差异，支持首个、上一个、下一个、末个差异、地址跳转及独立窗口；按相同字节偏移比较，插入 / 删除后不自动重新对齐。图片与 LFS 使用原有专用视图。
“使用外部合并程序查看”目前仍显示“暂未支持”的信息提示；二进制对比直接使用内置视图即可。
发布包使用 TreeGit-版本号-Windows-x64.zip 命名，版本及源提交另见 build-info.json；升级时保留自己的 data/ 目录。
