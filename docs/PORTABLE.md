# TreeGit Windows 便携版

完整解压后双击 `TreeGit.exe`，无需安装 .NET，也无需登录 TreeGit 账号。

1. 默认检测电脑现有的 Git。未检测到时，在偏好设置指定 Git，或把 Git for Windows 的便携组件解压到旁边的 `git/`，形成 `git/cmd/git.exe`。
2. 通过“文件”打开或克隆仓库。需要权限时会出现正常认证窗口；不同仓库的 HTTPS 账号可以独立保存。SSH 密钥按远程配置。
3. 在“偏好设置 → 外观 → 颜色风格”选择 **SourceTree**，可使用参考蓝白配色；**Light** 是 TreeGit Logo 的墨青配色，另保留 Dark 和 Default。
4. 图谱顶部的“未提交的更改”打开下方暂存、未暂存文件及差异。顶部“提交”按钮进入完整提交编辑视图。单击分支只调整图谱焦点；双击按原有行为检出分支。
5. 拖动历史表头之间的边界可调整图谱、描述、日期、作者及提交列宽，设置按仓库保存。文件列表和差异区之间也可拖动；较窄的文件框内，操作按钮会自动换行。
6. 在“工具 → MCP · AI 连接”复制当前实际路径的配置。默认完整读写，AI 可执行全部 Git 操作；需要限制写入时勾选只读连接。随包的 JSON 是路径模板，使用前需替换 `C:\Tools\TreeGit\TreeGit.exe`，更推荐直接从软件复制。详细能力见 `MCP-使用说明.md`。

偏好及缓存位于程序旁边的 `data/`。升级时关闭软件，保留旧 `data/` 后替换程序文件。已保存密码在当前 Windows 用户的系统凭据库中，不随便携目录一起复制。
