# TreeGit Windows 便携版

完整解压后双击 `TreeGit.exe`，无需安装 .NET，也无需登录 TreeGit 账号。

- **SystemGit** 文件名为 TreeGit-版本号-Windows-x64-SystemGit.zip。电脑已经安装 Git 时选择此包，下载体积更小。
- **BundledGit** 文件名为 TreeGit-版本号-Windows-x64-BundledGit.zip。包含 Git 及配套组件，可在没有本机 Git 的电脑上离线使用。
- 下载页的 SHA256SUMS.txt 提供两种包的 SHA-256。BundledGit-Identity.txt 供更新器比对内置 Git 版本及组件。

1. TreeGit 优先使用电脑上可用的 Git。随包的 Git 保存在 `git/` 目录的压缩包内，请保留该目录。没有可用的本机 Git 时，TreeGit 首次使用会离线解压，以后直接复用。在“工具 → 外部工具 → Git”中可以自动检测本机安装，或者勾选“使用内置Git”。本机 Git 路径失效时，下一次操作会切到内置 Git，并记住该选择。可写目录内首次启用成功后，会释放内部压缩包。准备只读介质时，请先在可写目录启用一次内置 Git，再将该目录复制到介质；直接在只读介质上首次启用，需要额外的用户缓存。已启动的提交或推送若被中断，可先查看仓库状态再决定是否重试。
2. 通过标签栏的 ＋ 打开、克隆或创建仓库。创建时可以同时建立 GitHub 远端。HTTPS 认证信息按仓库保存，可从“设置 → 远程仓库 → 账号与密码”修改或清除。SSH 密钥按远程配置。
3. 主题提供“跟随系统”、**Light**、**Dark**、**Blue**。选择“跟随系统”后，系统浅色时使用 Light、系统深色时使用 Dark，并随系统切换；配置和 MCP 中对应 `Default`。初次启动仍默认为 Light，升级保留现有选择。Light 顶栏为已确认的深绿色 `#16836D`，Dark 顶栏为深灰色 `#1F1F1F`，Blue 保留蓝白配色。
4. 底部为“搜索／日志・历史／提交”。图谱顶部的“未提交的更改”在历史下方打开暂存、未暂存文件及差异；顶部“提交”按钮和底部“提交”页进入完整提交编辑视图。单击左栏分支先回到日志 / 历史，保留图谱显示方式；双击当前本地分支不切换，其他本地分支先显示“切换本地分支”确认框，远程分支显示“检出远程分支”。
5. 拖动历史表头之间的边界可调整图谱、描述、日期、作者及提交列宽，设置按仓库保存。文件列表和差异区之间也可拖动；较窄的文件框内，操作按钮会自动换行。
6. 在“工具 → MCP · AI 连接”复制当前实际路径的配置。默认完整读写，AI 可执行全部 Git 操作；需要限制写入时勾选只读连接。随包的 JSON 是路径模板，使用前需替换 `C:\Tools\TreeGit\TreeGit.exe`，更推荐直接从软件复制。详细能力见 `MCP-使用说明.md`。

启动时优先恢复上次选中的仓库，其余仓库先保留标签，再逐步加载；点击尚未加载的标签会优先加载该仓库。后台完成加载不会改变当前选中的标签。外部编辑器发现和字体列表按需加载。

外观配置中的“界面字体”和“代码 / Diff 字体”均可从本机字体列表选择。首项显示当前默认字体，选择它可恢复默认；界面默认使用 Segoe UI / 微软雅黑回退，代码默认使用内置 JetBrains Mono。代码字体建议选择等宽字体，例如 Consolas。

偏好及缓存位于程序旁边的 `data/`。已保存密码在当前 Windows 用户的系统凭据库中，不随便携目录一起复制。

首次启动按系统语言选择简体中文、繁体中文，其余使用英语；后续以用户保存的语言为准。可在“编辑 → 语言/Language”悬停预览并点击确认。

提交页上方显示实际提交账号及分支，时钟按钮列出最近 10 条可达提交说明，含合并历史；点选插入光标处。下方可直接选择绕过提交钩子、署名及提交后立即推送。没有暂存文件时禁止输入与提交，并保留已有草稿。

在“帮助 → 检查更新”下载新版本，完成后点击“重启完成更新”。勾选“启动时检测软件更新”后，每次启动自动检测，发现新版本时提示；无更新或暂时无法连接时不打扰。

只在发现 TreeGit 新版并准备下载时检查所选 Git。系统 Git 可用时只下载并更新 TreeGit 程序。系统 Git 不可用时下载 BundledGit，安装成功后切换至内置 Git。选用内置 Git 时，随包版本及原装文件与新版一致才使用 SystemGit 更新程序，否则下载 BundledGit 修复或升级内置 Git。完整更新只覆盖随包文件，保留 git/ 中添加的其他文件。

打开、克隆或操作仓库时找不到可用的 Git，TreeGit 会询问是否下载最新版 BundledGit 修复。确认后下载并重新启动完成修复，即使 TreeGit 本身已是最新版。也可以手动安装 Git，或到发行页下载 BundledGit。

下载支持取消和续传。选择“后台更新”后可以继续使用仓库，下载完成或失败时会再次显示窗口；点击更新窗口右上角的关闭按钮可选择“取消更新”或“后台更新”。也可以先选“稍后”，下次重新打开检查更新时继续。正在执行仓库操作，或还有未处理的设置、操作窗口时，会提示先完成或关闭。程序会保存设置、替换文件并重新打开，个人配置、仓库、日志及自定义 MCP 配置保留；新版无法启动时自动恢复上一版。AI 连接会暂时断开，更新后可重新连接。

连接失败、磁盘空间不足或没有写入权限时，窗口会给出对应处理方式，并提供重试和手动下载。手动升级请先退出 TreeGit，保留原 `data/` 和自定义配置，再替换程序文件。

项目及更新：https://github.com/JonSun2020/TreeGit

基于 SourceGit 2026.24，保留原版权及 MIT 许可证；界面、品牌及 MCP 为 TreeGit 的改动。内置 Git、LFS、Git Flow 和配套组件遵循各自许可证，见 `git/COMPONENTS.md`。当前主要验证平台为 Windows x64。

二进制文件变更直接显示左右十六进制 / ASCII 差异，支持首个、上一个、下一个、末个差异、地址跳转及独立窗口；按相同字节偏移比较，插入 / 删除后不自动重新对齐。图片与 LFS 使用原有专用视图。
对比与合并默认使用 TreeGit 内置工具，二进制对比无需外部软件。文件编码可在对比工具栏的首个差异箭头左侧选择。自动模式优先使用文件头的编码标记，正文按行识别 UTF-8 和 GB2312。手动编码按仓库和文件类型保存，选回自动即可清除该覆盖。主界面和独立比较窗口分别记住其他显示设置。外部工具可在“工具 → 外部工具”中配置。
