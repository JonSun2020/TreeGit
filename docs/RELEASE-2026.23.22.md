# TreeGit 2026.23.22

- 搜索“分支”列改为“包含分支”，展示真正包含该提交的本地、远程分支；优先显示当前检出分支，存在多个分支时显示“＋数量”和下拉箭头。
- 点击展开完整列表，按本地、远程分组，支持名称筛选，并标出当前检出分支。本地与对应远程分支分别统计，远程信息以最近一次获取为准。
- 分支名采用无灰底的整行列表；仅悬停或键盘聚焦的分支行高亮。组标题为独立、不可选中的行，悬停第一条分支不会改变组标题背景。
- 点击具体分支后进入日志／历史，选中原提交并展开左栏对应分支，不执行检出，也不跳到该分支的最新节点。原有双击搜索结果跳转行为保留。
- 批量搜索复用一次引用快照和一次历史遍历，支持多代派生、合并、本地落后远程及较多分支；不把跟踪关系误算为本地已包含提交，也不重复统计远程 HEAD 别名。
- “包含”指历史包含关系，后续 revert 不会移除原提交；本版不自动判断改动是否仍然生效。
- MCP 增加包含分支列表的展开、筛选及指定分支定位控制，并返回每条结果的分支数量和完整引用。

安装包：`TreeGit-2026.23.22-Windows-x64.zip`。已有可在线更新的版本可通过“帮助 → 检查更新”升级，保留个人配置。
