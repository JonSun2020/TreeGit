# SourceGit 功能入口对照

TreeGit 调整页面与入口，保留 SourceGit 的 Git 命令、工作流及配置能力。移除重复的工具栏按钮时，功能移到顶部菜单或对应的右键菜单。MCP 是额外控制入口。

| SourceGit 功能 | TreeGit 的界面入口 |
| --- | --- |
| 打开、克隆仓库 | 文件 → 打开 / 克隆仓库；欢迎页 |
| 切换工作区、管理工作区 | Ctrl+Alt+P |
| 搜索、切换已打开仓库 | Ctrl+P |
| 提交、修改上次提交、签署提交、修改作者 | 顶部提交 → 完整提交编辑页 |
| 自动暂存后提交、提交并推送 | 完整提交编辑页按钮及原快捷键 |
| 暂存、取消暂存、部分暂存 | 图谱顶部未提交更改 → 文件列表、差异行上下文菜单 |
| 获取、拉取、推送及高级选项 | 顶部对应按钮；操作菜单；原有对话框 |
| 拉取/推送未同步数量 | 仓库标签、对应按钮角标及分支树 |
| 新建、切换本地分支、检出远程分支、重命名、删除分支 | 顶部分支；左栏分支双击及右键菜单；切换和检出先确认 |
| 合并、变基、交互式变基 | 顶部合并；分支和提交右键菜单 |
| 重置、回退、挑选、变更提交信息 | 提交右键菜单 |
| 重排、合并、压缩提交 | 多选提交及交互式变基的原有页面 |
| 新建、删除、推送标签 | 顶部标签；标签树及提交右键菜单 |
| 远程仓库增删改、SSH 密钥 | 设置 → 远程仓库；远程树右键菜单 |
| 独立推送地址及远程高级操作 | 远程树右键菜单中的原有入口 |
| 仓库账号与密码 | 工具 → 仓库账号与密码；认证时自动弹窗 |
| 贮藏、应用、弹出、删除贮藏 | 顶部贮藏；侧栏贮藏；列表右键菜单 |
| 丢弃更改 | 顶部丢弃；文件列表右键菜单 |
| 冲突处理、外部合并工具 | 冲突文件及原有冲突面板 |
| 子模块增删改、更新 | 操作 → 高级操作 → 添加子模块；侧栏子模块及其右键菜单 |
| 工作树创建、打开、移除、修剪 | 操作 → 高级操作 → 添加工作树；侧栏工作树及分支右键菜单 |
| Git Flow | 操作 → 高级操作 → Git 工作流 |
| Git LFS | 操作 → 高级操作 → Git LFS |
| Bisect 二分查找 | 操作 → 高级操作 → 二分查找；进行中的原有操作面板 |
| 补丁保存、应用 | 提交/差异右键菜单；操作 → 高级操作 → 应用补丁 |
| 文件、目录历史及 Blame | 文件列表及提交文件树的右键菜单 |
| 版本比较、分支比较、图片差异 | 提交与分支右键菜单；原有差异页面 |
| 找回重置或删除分支后丢失的提交（Reflog） | 操作 → 高级操作 → 找回丢失的提交；在图谱中查看后可新建分支保留 |
| 导出归档 | 提交右键菜单 |
| 搜索提交 | 底部搜索；原搜索快捷键 |
| 外部工具、终端、资源管理器 | 顶部命令行模式、资源管理器；工具 → 外部工具 |
| 命令日志、统计、清理仓库 | 操作 → 高级操作中的对应条目 |
| 用户信息、忽略文件、提交文本链接 | 设置 → 高级 |
| 提交模板、签名、代理、合并默认值、子模块策略 | 设置 → 高级中的同步、签名、子模块及模板分组 |
| 工作区偏好、外观、主题、编辑器、差异、Git | 编辑 → 偏好设置 |
| 规范提交构建器 | 完整提交编辑区的原有工具 |
| PR 创建、Issue 链接 | 远程/分支/提交原有菜单；设置 → 高级 |
| 软件更新、快捷键、数据目录、关于 | 帮助；帮助 → 诊断与数据 |
| AI 查询和完整 Git 操作 | 工具 → MCP · AI 连接；`git_run` 覆盖全部 Git 子命令 |

Windows 标准便携包已包含 Git、OpenSSH、LFS 和 Git Flow 组件；优先自动使用电脑上已有且可用的 Git，必要时回退到内置组件。外部编辑器与外部合并工具仍需用户自行安装和选择。直接查看二进制差异无需外部工具。

维护时同时核对控件/绑定保留检查、真实 Git 操作验收和实际菜单入口。仅保留代码或隐藏按钮，不作为“已有可用入口”的依据。

按用户要求简化了非 Git 扩展的配置界面：内置 AI 文本生成、自定义操作编辑、JSON 主题覆盖及头像服务开关。已有配置数据保留；Git 操作和 MCP 读写能力继续保留。
