# TreeGit 2026.24.2（预览）

- 勾选“启动时检测软件更新”后，每次启动都会自动检测。发现新版本时打开更新窗口；没有更新或暂时无法连接时保持安静。
- 更新窗口增加“后台更新”。下载和校验在后台继续，完成或失败时重新显示窗口，由用户决定重试或重启安装；后台期间仍可正常使用仓库。
- 在可下载、下载中或校验中关闭更新窗口，会提示选择“取消更新”或“后台更新”。关闭选择框本身不会取消下载；取消后的有效下载片段仍可续传。
- 变更对比中的提交、父提交、作者、日期、提交者和完整提交说明支持选择、复制。右键提供复制选中文本、复制全部文本；SHA 另有“复制完整 SHA”。
- 提交及父提交显示为 `完整 SHA [10 位简要 SHA]`；简要长度沿用现有 SourceGit 显示规则，复制完整 SHA 不带方括号后缀。父提交旁的独立跳转按钮保留导航功能。

此版本尚未正式发布，正式下载与在线更新仍指向上一正式版本。
