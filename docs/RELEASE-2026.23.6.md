# TreeGit 2026.23.6

- 标准 Windows 包自带便携 Git：优先自动使用电脑上已有且可用的 Git，未找到可用版本时自动使用内置组件，无需另装 Git、改系统 PATH 或联网下载。
- 检测覆盖当前用户与系统安装、32/64 位注册信息、PATH 及常见安装目录。跳过失效路径、无法运行或低于支持版本的程序，检测有超时限制。
- 修复损坏的 Git 文件在 Windows 创建进程阶段阻塞启动的问题：先检查可执行文件格式，局部抑制系统底层错误弹框并恢复原线程状态；无法使用时显示可操作的提示。MCP 同样返回完整解压或指定 Git 的说明。
- 上次自动使用内置 Git、之后安装了系统 Git 时，下次启动会重新检测。复制到其他电脑后失效的旧 Git 路径也会重新选择；有效的手动指定路径继续保留。
- Git 命令的 SSH 与配套 PATH 跟随实际选中的运行组件，避免系统 Git 和内置 SSH 混用。MCP 状态增加实际 Git 路径、版本及是否内置，便于诊断。
- 内置官方 MinGit 2.56.0.windows.4、Git LFS 3.8.1、Git Flow Next 2.1.0，保留许可证和来源；构建校验下载文件，打包逐项核对运行组件，拒绝缺失、被改动或夹带额外文件的组件目录。
- 保持主界面和常用操作入口不变。内置组件不提供交互式 Git Bash、Perl 或 Tcl/Tk；终端默认可使用 Windows PowerShell / cmd，额外工具及特殊 hooks 仍需要其对应环境。

完整解压 `TreeGit-2026.23.6-Windows-x64.zip`，运行 `TreeGit/TreeGit.exe`。升级时关闭软件，保留自己的 `data/`，替换程序及随包 `git/`。组件均已包含，未安装 Git 的电脑也可离线启动和执行本地 Git 操作。
