# TreeGit 2026.23.21

- 搜索结果在“描述”左侧增加可调整宽度的“分支”列，显示与跳转侧栏选择一致的分支名称；远程分支包含远程名称。
- 分支匹配支持较早提交及本地与远程跟踪关系，批量解析搜索结果，避免为每行重复启动 Git。
- 底部“文件状态”“日志 / 历史”“搜索”统一为原搜索按钮的 104 × 26 尺寸，文字上下左右居中。当前页使用浅色底和贯通上沿，未选中项保留实色底与边框。
- 保留搜索双击跳转、自动显示所有分支与远程分支、展开并选中对应分支的行为。

- 修正侧栏拉宽、历史左右布局及记忆分栏宽度导致的内容越界；窄区域可滚动访问完整内容，切换页面回到新页面起点。
- 历史、工作区、提交编辑器、贮藏和差异面板保留可操作的最小区域；长提交说明单独滚动，窄历史工具栏自动换行。
- 文件历史、目录历史、分支比较、“关于”、MCP 连接与 SSH 管理窗口适配小屏幕和缩放，关键按钮保持可访问。
- 二进制对比根据左右面板实际宽度选择每行字节数，极窄窗口下完整显示十六进制和 ASCII 数据。
- 缩放和适配小窗口不会覆盖用户设定的侧栏宽度；滚动条临界尺寸保持稳定。
- 修复连续取消暂存后立即“暂存所有”可能漏文件的问题：批量操作读取最新状态，遵守当前文件筛选；暂存、取消暂存与提交避免同时操作索引，失败时保留所选文件、恢复按钮并清理临时文件；没有可操作文件或未选择文件时，相关按钮置灰。

安装包：`TreeGit-2026.23.21-Windows-x64.zip`。
