# TreeGit 2026.23.24

- 内置可编辑的合并工具：上方并列显示 Local、Base、Remote，下方直接编辑合并结果。右键选择“仅左边”“仅右边”“先左后右”“先右后左”，已处理的冲突可复原，也可通过顶栏撤销。
- 冲突处理显示当前编号、固定的冲突总数和剩余未解决数量；选中区域及行号同步高亮，解决后立即变绿。保存并暂存成功后关闭窗口；取消和关闭会保护尚未保存的编辑。
- 工作区有修改时仍可发起合并，冲突交给合并工具处理。临时贮藏按本次操作精确恢复，失败时保留可恢复的数据；未跟踪文件、忽略文件、子模块和目录链接均纳入覆盖检查。
- 修复点击“未提交的更改”时节点和文字先向右移动再归位的问题。没有本地更改时隐藏该节点；合并尚未提交时，图谱同时连接当前提交和待合入提交，滚动后顶部节点保持固定。
- 提交右键菜单直接提供检出、合并、变基、标签、存档、分支、交互式变基、重置、回滚、创建补丁、遴选和复制 SHA。其余比较、推送及提交编辑等能力保留在“高级操作”；右键始终针对鼠标指向的提交。
- 强化合并、拉取、切换分支、贮藏和丢弃更改的失败恢复。操作前后核对目标，避免源分支移动、状态读取失败或认证错误导致误操作；失败后保留工作区内容、暂存状态、原有贮藏和提交草稿。
- MCP 增加冲突结果的读取、编辑、逐块选择、复原、撤销和保存并暂存；搜索结果及包含分支信息支持分页，减少大量提交和分支时的数据传输。

保留内置二进制文件左右对比，无需外部工具；保留 SourceGit 的原有 Git 能力及已确认的 SourceTree 风格主界面。冲突编辑支持文本文件；二进制和子模块冲突保留各自的专用处理入口。

安装包：`TreeGit-2026.23.24-Windows-x64.zip`。已有可在线更新的版本可通过“帮助 → 检查更新”升级，保留个人配置。标准便携包包含 Git、OpenSSH、Git LFS 和 Git Flow；优先使用本机可用 Git，必要时回退到随包组件。
