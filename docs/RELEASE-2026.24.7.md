# TreeGit 2026.24.7

- 主窗口与 Git 检测并行初始化，当前仓库优先就绪，其余仓库在后台恢复。历史记录的分支图计算和仓库文件监视也减少了重复工作。
- Windows 便携包默认以压缩形式保存内置 Git。系统 Git 可用时直接使用系统 Git。首次启用内置 Git 时按需离线解压，验证成功后释放压缩包，后续启动复用已经展开的文件。系统 Git 路径在使用过程中失效时，可自动切换到内置 Git。
- “工具 → 外部工具集成”集中显示系统 Git 路径和版本，也可查看并选择内置 Git。取消勾选内置 Git 时会自动检测系统 Git。终端和对比／合并工具的输入区与 Git 配置对齐。
- 未选中的复选框保留清晰的方框边线，随选项失效的说明、输入框和下拉框变灰并禁用。
- 定时自动拉取间隔支持 1–9999 分钟，输入自动保留数字，聚焦时仍可用滚轮调整。点击“分钟”可勾选或取消，未启用时点击数字框也会启用并聚焦输入框。

Windows x64 便携版内含 Git 和运行时。现有用户可从“帮助 → 检查更新”升级。
