# TreeGit 2026.24.13

## Windows x64 便携包

- **SystemGit** 适合已安装可用 Git 的电脑，下载较小。
- **BundledGit** 随附 Git、OpenSSH、Git LFS 和 Git Flow。适合没有 Git、离线使用或修复内置 Git 的电脑。
- 两种包均可解压即用。SHA-256 见发行附件 SHA256SUMS.txt。

## 更新与修复

- 更新器根据当前 Git 状态选择最小可用的包。系统 Git 可用时只更新 TreeGit 程序。使用内置 Git 时，会验证现有组件并对比版本，必要时更新内置 Git。
- 执行 Git 操作时若找不到可用 Git，可确认下载 BundledGit 自动修复。已是最新版也能修复。升级保留个人配置和 Git 目录中的自定义文件。
- HTTP 远端没有显式 Git 或进程代理设置时，系统 Git 与内置 Git 均可使用 Windows 系统代理。

## 界面

- 文本选区使用对应主题的主分支选中色。拖选中英文之间的空格时，字符位置和换行保持稳定。
- 仓库标签保留已有选择。首次查看时优先显示未提交的更改和首个已跟踪的未暂存文件，工作区干净时按图谱模式选择最新提交。

## 对比与稳定性

- 文本对比复用进行中的相同查询，减少切换文件时重复启动 Git。更改编码、上下文或手动刷新时重新读取。
- 二进制对比逐字节跳转，当前差异用加深的红绿底色及粗体突出。左右视图共用可见区域的数据，同一屏内切换差异无需重复读取。
- 修复切换或关闭仓库标签时，文本对比面板访问已移除行可能导致的崩溃。
- 仓库账号与密码窗口打开远程名称下拉框时保持滚动位置。偏好设置窗口更紧凑，提交详情默认进入变更对比。
