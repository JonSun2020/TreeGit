# TreeGit 2026.23.11

- 启动时优先恢复上次选中的仓库，其他仓库先显示标签，再逐步加载；点击未加载标签会立即优先加载，不等待前面的仓库。后台加载不会切走当前标签。
- 未加载标签的关闭、移动、顺序保存和重启恢复均保留。仓库路径失效时显示错误，不妨碍其他仓库使用；关闭尚未加载的仓库后，后台任务不会重新打开它。
- 字体设置改为可选列表，显示当前默认字体；“缺省字体”改名为“界面字体”，“等宽字体”改名为“代码 / Diff 字体”。支持本机字体选择、恢复默认，兼容旧版自定义字体配置。列表只在打开设置或明确查询时加载。
- 外部编辑器发现改为按需执行。MCP 增加字体选择，以及标签加载状态和移动操作。
- 保留跟随系统、Light、Dark、Blue；保留内置二进制左右对比，无需外部工具。

完整解压 `TreeGit-2026.23.11-Windows-x64.zip` 后运行 `TreeGit/TreeGit.exe`。升级前退出程序并保留个人 `data/`，程序包已包含 Git 组件。
