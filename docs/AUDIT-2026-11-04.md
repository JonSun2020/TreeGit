## 检查点 4：组合失败回滚

- 新增反例已在旧检查点复现：同时修改 Git 身份和仓库选项，最后的设置写入失败时，Git 身份已被部分保存。
- 保存改为使用 Git 标准锁保护临时副本；所有文件准备好后再替换。普通失败会还原已经替换的文件，并保持原内存设置；锁由系统在句柄关闭/进程退出时释放，不删除其他程序已有的锁。
- 设置回归扩展到 30 项并通过，覆盖写入前失败、只读文件导致最终替换失败、Git 身份/链接/设置共同还原、锁释放及恢复后重试。
