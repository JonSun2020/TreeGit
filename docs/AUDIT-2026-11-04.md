- 所有写入、冲突和失败实验只使用独立临时仓库，不操作用户项目。
- 除正常流程，还要覆盖取消、错误、重试、连续切换、特殊路径、多仓库和缩放。
- 检查 Git 实际文件/配置/提交结果，同时查看真实 UI 状态和截图。
- 验证常用入口不回退，低频功能通过“操作 → 高级操作”或原有上下文菜单到达。
- 未实际运行的检查明确保留为待完成；不以编译成功代替功能正确。
