# TreeGit 2026.23.3

- 二进制文件变更增加旧版本 / 新版本左右十六进制、ASCII、偏移地址及红绿差异高亮。支持差异导航、地址跳转和独立窗口；大文件按块读取，并在后台扫描差异。
- 覆盖工作区与暂存区、暂存区与 HEAD、提交历史的二进制文件，支持重命名、添加、删除和空文件。
- “使用外部合并程序查看”和手动“检查更新”改为“暂未支持”的普通信息提示，避免显示错误弹框。
- 发布压缩包改为带版本号的 `TreeGit-2026.23.3-Windows-x64.zip`，自动构建与本地打包使用相同规则。
- MCP 增加 ui_diff，支持选择变更文件、读取二进制对比状态与差异导航。

二进制视图只读，按相同偏移比较，不会对插入 / 删除后的字节自动重新对齐。图片及 LFS 保留原有专用视图。

完整解压后运行 TreeGit/TreeGit.exe，无需安装或登录。保留原 data/ 目录即可升级；压缩包不含用户配置、缓存或凭据。HTTPS 使用 OpenSSL，SSH 使用 OpenSSH，全部 Git 操作继续通过原有流程和 MCP 提供。
