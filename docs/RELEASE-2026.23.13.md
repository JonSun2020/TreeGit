# TreeGit 2026.23.13

本版保留已确认的 围绕便捷性和直观性优化的主界面、SourceGit 基础功能、MCP 读写控制，以及不依赖外部工具的二进制左右对比，集中修复实际操作和异常恢复中的问题。

- 修复 Git 大量输出时部分查询或取消暂存可能卡住的问题；导出失败时保留已有目标文件。
- 修复“修改上次提交”中的文件属性、重命名、特殊路径和 SHA-256 仓库处理，支持完整选择及部分文件取消暂存。
- 收紧认证重试范围。本地提交或推送钩子拒绝操作后立即停止，保留草稿和暂存内容；真正的远端账号或密码错误仍可重新输入。
- 仓库暂时无法读取或配置损坏时给出打开失败提示，避免错误地进入初始化流程；只读探测遇到无输出失败时最多重试一次。
- Windows 拒绝创建 Git 子进程时，在确认进程尚未建立的条件下进行有限重试；Git 已执行后返回失败不会因此重跑。
- 二进制读取出错时提供简明提示和原处“重试”，恢复后继续显示真实字节与差异。
- 二进制独立对比窗口会为系统标题栏和窗口边框预留空间，在较小屏幕上保持可见并按宽度调整每行字节数。
- 补齐便携 Git 的 SSH 密钥生成工具，电脑没有系统 Git／SSH 时也可生成密钥；已有私钥或公钥不会被覆盖或当作新生成成功。
- 改进损坏或被占用配置的恢复、保存草稿后关闭、运行中操作保护，以及更新前保存和失败回退流程。
- 关于窗口底部署名为 `Copyright © 2026 TreeGit contributors.`，保留基于 SourceGit 的说明和原有许可证。

完整解压 `TreeGit-2026.23.13-Windows-x64.zip` 后运行 `TreeGit/TreeGit.exe`，无需安装或登录。2026.23.12 可通过“帮助 → 检查更新”升级；更早版本请先手动下载新版。
