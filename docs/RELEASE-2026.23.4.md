# TreeGit 2026.23.4

- “＋”新标签页的克隆、打开、终端、分组和扫描按钮，使用与仓库工具栏一致的固定图标行、文字行及垂直居中布局，消除图标和文字偏上、不平齐的问题。
- 自动认证时的用户名、密码、SSH 密钥口令提示，以及仓库账号设置窗口，在打开后保持置顶并激活，避免被其他窗口遮挡。

- 修复空分支 / 初始仓库标签 X 左侧残留的同步徽标竖条；仅有实际推拉数量时显示徽标。
- 贮藏与远程改为同级可展开分组，条目显示在侧栏，右侧展示所选贮藏的文件及差异；切换贮藏保留侧栏宽度和布局，保留应用、删除、建分支、导出补丁等原有操作。
- 保留 2026.23.3 的二进制左右对比、普通“暂未支持”信息提示及带版本号的压缩包。
