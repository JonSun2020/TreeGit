# TreeGit 2026.24.14

## Windows x64 便携包

- **SystemGit** 适合已安装可用 Git 的电脑，下载较小。
- **BundledGit** 随附 Git、OpenSSH、Git LFS 和 Git Flow，适合没有 Git 或需要修复内置 Git 的电脑。
- 两种包均可解压即用。SHA-256 校验值见发行附件 `SHA256SUMS.txt`。

## 推送和认证

- 单分支推送的预检和执行只处理指定目标。远端拒绝写入时显示对应的权限提示。
- 通过 MCP 选择系统认证时，沿用 Git 已配置的认证助手与凭据范围。缺少凭据时可在同一窗口输入账号和密码或令牌，输错可重试，取消会停止操作。
- 禁用交互且缺少凭据时，MCP 返回认证错误。

## 界面

- 图谱的分支范围与排序、变更的筛选与排序、文件编码，均按当前语言中最宽的选项调整框宽。收起值和展开选项左对齐，切换选项时宽度保持稳定。
- 精简工作区变更栏。变更显示模式入口靠右，两个暂存操作和两个取消暂存操作各自并排。
- 收紧复选框、仓库高级设置和外部工具窗口的间距。下拉列表的选中项使用当前主题配色。
- 检查更新和无法更新时的窗口尺寸保持一致，手动下载入口与重试按钮样式统一。
