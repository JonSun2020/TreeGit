# TreeGit 2026.24.10

- 二进制对比在两侧数据读好后立即显示可滚动的十六进制和 ASCII 内容，随后统计全部差异。等待统计时可查看文件和跳转指定偏移。
- 独立窗口复用当前对比已读取的数据和差异索引。主窗口切换文件后，独立窗口仍可继续查看原来的对比。
- 加快整文件差异扫描，减少重复的 Git 查询和临时内存分配。两侧各 128 MiB 的本机测试中，稀疏差异扫描中位数从约 261 毫秒降至 88 毫秒，密集差异从约 247 毫秒降至 83 毫秒。

初次安装和手动升级请使用 Windows x64 完整便携包。已有用户可通过「帮助 → 检查更新」升级，满足条件时自动使用轻量更新包。
