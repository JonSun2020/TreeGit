## 本轮修正

- Git 大输出与输入管道阻塞、失败导出覆盖已有文件、凭据模式缓存失效竞态。
- 初始化仓库元数据未完成时的同步操作、无输出探测失败、配置损坏或保存失败后的恢复与关闭保护。
- 修改上次提交的索引模式、特殊路径、SHA-256；无效或异常 LFS 指针处理。
- 本地提交／推送钩子被误当成远端认证失败而重跑，及二进制读取错误的恢复入口。
- 便携包缺少 SSH 密钥生成工具、小屏幕独立对比窗口的系统边框与标题栏边界。
