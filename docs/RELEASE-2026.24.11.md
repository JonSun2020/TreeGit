# TreeGit 2026.24.11

- 拉取、推送、获取连接失败时，底部运行条立即停止，保留错误提示。重新尝试时恢复进度显示。
- 修复共用输入框光标与文字重叠的问题。扫描仓库的根路径可直接输入或浏览，初始值来自偏好设置的默认克隆路径。
- 文件编码的「自动适配」随界面语言即时更新。外部工具的「对比/合并」页按项名宽度对齐，切换工具时填写框保持位置和宽度。
- 主栏「设置」移到「工具」左侧，仓库页右侧入口更名为「仓库配置」。统一弹窗字段的标点和按钮尺寸，改善创建仓库时依赖选项的禁用状态。

首次使用请下载 Windows x64 完整便携包。已有用户可通过「帮助 → 检查更新」升级，满足条件时使用轻量更新包。
