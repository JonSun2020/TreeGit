# TreeGit 2026.24.6

- 文本差异支持逐行识别 UTF-8 和 GB 编码。一个文件里相邻行采用不同编码时也能对照阅读，整行使用同一种编码。显示选项可手动指定编码，切换只影响查看。
- 内置文本对比的主界面和独立窗口分别记住显示设置。主界面默认上下对比，独立窗口默认左右并排显示完整文件，两侧长行换行后对应行保持对齐。二进制文件仍可直接左右比较。
- 拉取、推送或获取需要认证时，可在同一窗口输入账号和密码。验证失败可修改后重试，取消会结束本次请求。仓库设置支持修改或清除该仓库保存的 HTTPS 账号。
- 修复 Windows 上 Git LFS 在首次输入账号和密码时可能卡住的问题。上传时可重新输入凭据，取消后保留本地修改。
- 远程操作显示进度及可复制的完整输出，错误行用红色标识。可在执行中取消，操作结束后可查看结果再关闭。
- 从新标签页可打开、克隆或创建仓库，创建本地仓库时可同时在 GitHub 创建远端。标签页内的弹窗支持拖动，最后一个空白标签页可保留为入口。
- 第三方比较工具集中在“工具 → 第三方工具集成”。修正悬停提示残影、首次打开选框的底色，以及 Blue 主题单选框的显示。选中项采用深蓝圆点和亮蓝外圈。
- 交互式变基窗口在高缩放比例下会将选项和操作按钮分行显示，缩小窗口后仍可操作。

Windows x64 便携版内含 Git 和运行时。现有用户可从“帮助 → 检查更新”升级。
