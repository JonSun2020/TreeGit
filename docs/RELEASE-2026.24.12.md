# TreeGit 2026.24.12

- 文本对比支持按仓库选择 5、15、50 行上下文或完整文件。主窗口和独立对比窗口各自记住设置，独立窗口默认显示完整文件并关闭自动换行。修复最大化、还原以及 Dark 主题语法高亮下的文字选区。
- 提交详情的「基本信息」「变更对比」「文件列表」统一文件选中色。提交信息和变更文件之间可上下拖动，分界位置按仓库保存。
- 提交与侧栏分支、标签联动时会滚动到对应项。折叠状态保留关联提示，展开后定位到对应分支或标签。独立的内置对比窗口可按区块暂存、取消暂存或丢弃工作区更改。
- 统一 Windows 本地路径显示及可选文字的主题配色。修复仓库配置页切换时窗口跳动、贮藏选项截断，以及下拉列表与选框的对齐问题。
- 减少分支同步状态和文本差异查询的处理开销，压缩内置 Git 清单。

首次使用请下载 Windows x64 完整便携包。已有用户可通过「帮助 → 检查更新」升级，满足条件时使用轻量更新包。
