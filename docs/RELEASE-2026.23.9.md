# TreeGit 2026.23.9

- 主题选项简化为 `Light`、`Dark`、`Blue`，默认使用 `Light`。旧配置中的 `Default` 自动转为 `Light`，不再跟随系统主题。
- 修正切换 `Dark` 后顶栏仍为绿色的问题：顶栏和标签边缘采用深灰色 `#1F1F1F`，悬停为 `#333333`，文字保持白色；未选中标签也使用深灰色背景。
- `Light` 使用已确认的深绿色顶栏 `#16836D`、悬停色 `#126D5B` 和白色文字。`Blue` 保留蓝白配色。

完整解压 `TreeGit-2026.23.9-Windows-x64.zip` 后运行 `TreeGit/TreeGit.exe`。升级时退出程序并保留个人 `data/`，程序包已包含 Git 组件。

本次修改仅涉及主题选择、旧配置兼容及主题颜色。主界面布局、常用入口、Git 自动识别与内置回退、MCP 读写功能沿用既有实现。
