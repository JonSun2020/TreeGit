# TreeGit 2026.24.1

同步 SourceGit 正式版 2026.24（master 发布提交 `2735a8ad80c2443bc736b7e6e501f1052b61d940`），保留 TreeGit 自行开发的功能和交互。

- 修复分支与标签同名时的推送歧义、无跟踪分支时本地变更数量、侧栏刷新、剪贴板异常以及已暂存且重命名图片的对比路径。
- 补丁文件支持拖入选择框；邮箱格式补丁可通过 git am 创建提交，沿用 TreeGit 的草稿保留、逐块冲突编辑和本地文件保护。
- 同步单分支删除时的关联工作树选项、分支名复制快捷键、命令日志退出处理及图片解码依赖更新。
- 新增和删除的文本文件只显示有内容的一侧；内置二进制左右对比继续保留。
- 提交变更对比的说明区域增加分支名框；无法确认原始分支时按图谱推定，并在悬停提示中说明。多个分支包含此提交时，可通过数量与省略号查看完整列表，只有一个分支时隐藏按钮。
- 选择提交或单击搜索结果时，左栏突出显示所有包含该提交的分支，主分支底色较深。同一分支同时存在本地跟踪和远程引用时，优先突出本地跟踪分支；手动选择分支采用相同底色。
- 修复刷新及搜索跳转后，旧提交已被选中但未完整滚入可视区域的问题；后台刷新保留用户正在浏览的位置。改善按住鼠标刷新、多选和右键菜单的目标一致性。
- Git 查询失败时保留已有分支、历史、搜索结果和选中项，避免把失败当成空列表或成功结果。后台仓库概览只读查询不再刷新索引缓存；取消只读查询时回收对应进程。
- 冲突编辑保留所选内容原有的末尾换行状态，支持两种变基方式及 merge、diff3、zdiff3 冲突格式；保存或暂存失败保留编辑内容，可修正问题后重试。
- 修复 MCP 连接与桌面启动之间的竞争，避免重复窗口及连接流未释放；完善只读模式对编辑、保存和 Git 写入操作的限制。默认连接仍支持完整读写。

主工具栏、统一布局的设置页、主题与标签配色、图谱最左侧当前分支、搜索跳转与分支衍生信息、仓库凭据、Local / Base / Remote 冲突工具、在线更新和 MCP 均沿用 TreeGit 的实现。当前分支筛选继续使用现有下拉框，不新增另一套筛选按钮，不恢复已删除的设置入口。

安装包：`TreeGit-2026.24.1-Windows-x64.zip`。完整解压后运行 `TreeGit/TreeGit.exe`；已有支持在线更新的版本可使用“帮助 → 检查更新”。

- 修复后台刷新重建冲突页而使“用合并工具编辑”按钮闪现、点击可能丢失的问题；同一文件保持当前页面并更新内容，过期查询不会覆盖新状态。
- 修复放大界面后点击固定的“未提交的更改”行可能触发整个页面滚动的问题。
