# TreeGit 2026.23.12

- “帮助 → 检查更新”可以直接下载新版，准备好后点击“重启完成更新”，程序会保存设置、替换文件并重新打开。
- 下载支持取消、续传，关闭窗口后可再次打开继续。网络异常、空间不足、权限不足或文件被占用时给出清晰提示，可重试或手动下载。仓库操作未结束时不会开始替换程序。
- 更新保留个人设置、日志、仓库和自定义 MCP 配置；替换中断可恢复，新版无法启动时自动回退上一版。更新期间 AI 连接暂时断开，完成后可重新连接。
- 启动优先恢复上次选中的仓库，其他仓库先保留标签，再逐步加载；点击未加载标签会优先加载。后台加载不改变当前标签。修复恢复标签时意外先加载第一个仓库的问题。
- 字体改为可选的本机字体列表，明确区分“界面字体”和“代码 / Diff 字体”，支持恢复默认并兼容原字体配置。字体及外部编辑器列表按需加载。
- 保留已确认的 SourceTree 风格主界面、跟随系统 / Light / Dark / Blue 主题、自动识别系统 Git 和内置 Git 回退，以及无需外部工具的二进制左右对比。

完整解压 `TreeGit-2026.23.12-Windows-x64.zip` 后运行 `TreeGit/TreeGit.exe`，无需安装或登录。程序包包含 Git 组件。

2026.23.10 及更早版本需手动升级本次版本；本次起可在程序内更新。手动升级前退出 TreeGit，并保留个人 `data/` 和自定义配置。
