# TreeGit 2026.23.5

本版保持已确认的主界面、图谱和常用操作入口，集中修正功能、失败恢复和数据边界。

- 修复合并、挑选、回退、变基及补丁导入失败时的提交草稿丢失；中止失败保留 Git 恢复资料，解除索引占用后可以重试。
- 修复连续冲突、关闭仓库后从终端推进流程时的提交说明串用；保留用户编辑及原有正文，默认说明清理 Git 生成的冲突提示。关闭自动刷新后，显式操作仍主动更新界面状态。
- 修复特殊文件名和子模块名被当作通配符的问题；部分暂存、取消暂存、丢弃、贮藏和冲突选择只作用于所选路径。
- 修复二进制差异重复选择时反复加载、缓存内容串用及损坏对象被当作空版本的问题；归档失败时保留已有输出。
- 改进仓库设置的原子保存与失败回滚；修复高缩放下部分子窗口超出屏幕的问题。仓库认证配置变更后及时失效旧缓存。
- 支持合法的 SSH 地址、SSH 配置别名和本地 bundle 克隆；修复带空格、中文、单引号的私钥路径。验证加密私钥口令置顶输入及输错后的重试。
- 修复独立 LFS 推送缺少提交引用的问题，上传当前 HEAD 所需对象；推送失败保留重试窗口。修复二分查找完成状态及结果导航。
- MCP 原始 Git 命令正确处理前置选项、目标仓库与认证范围；并发控制、重复选择和进程退出有专项检查。
- 发布包只包含程序、许可证、说明和空 data 目录，排除本地配置、缓存、测试驱动、SDK 和整套 Git。

下载 `TreeGit-2026.23.5-Windows-x64.zip`，完整解压后运行 `TreeGit/TreeGit.exe`。升级前关闭软件，保留自己的 `data/` 目录。无需安装 .NET，也无需登录 TreeGit 账号；默认使用电脑已有的 Git。

主要验收平台为 Windows x64。Git Flow、Git LFS 和外部工具仍需要对应外部组件；二进制差异按相同偏移比较，不自动对齐插入或删除后的字节。手动“检查更新”和“使用外部合并程序查看”仍按现有约定显示“暂未支持”。
