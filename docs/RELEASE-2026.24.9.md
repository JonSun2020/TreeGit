# TreeGit 2026.24.9

- 在线更新发现新版后会检查 TreeGit 自带 Git 的版本和文件。条件满足时自动选用只含程序文件的轻量更新包。内置 Git 有变动时使用完整包，并保留用户放入 Git 目录的额外文件。
- 提交页优先显示选中文件的差异。连续切换文件会取消已离开文件的查询，提交说明和分支归属随后加载，签名在查看提交信息时读取。
- 文本对比的「文件编码」位于首个差异箭头左侧。手动选择按仓库与文件类型记住。自动模式优先识别文件头的编码标记，正文按行判断 UTF-8 和 GB2312。
- 二进制对比隐藏文件编码选项。右侧以 ASCII 显示可打印字节，其余字节显示为点。

初次安装和手动升级使用 Windows x64 完整便携包。已有版本可用「帮助 → 检查更新」升级。轻量包由支持此功能的客户端自动选择。
