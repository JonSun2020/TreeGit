此次发现并修复两处问题：后台刷新重建冲突页可能丢失按钮点击；详情切换时把底部标签状态变化误当作页面变化，重置了外层滚动位置。后者在放大界面时表现为纵向跳动。最初仅调整焦点未能消除问题，已恢复原有键盘焦点行为，改为只在真正切换页面时重置滚动。

另外发现原有 Windows GUI 测试步骤可能缺少结果文件却仍被 CI 放行。已加入独立 Python 驱动，等待测试进程结束，并核对必需结果、检查数量及失败字段；严格复核通过。还修复了模型测试收尾无法删除 Windows 只读 Git 对象的问题；清理不跟随目录链接。这些是测试门禁及夹具修正，不据此声称产品曾发生更新失败。

这些检查覆盖本次涉及的历史修复和组合场景，不能证明软件不再有任何缺陷。后续新增复现应继续补入对应回归，保留首次失败记录，不通过放宽断言掩盖问题。
