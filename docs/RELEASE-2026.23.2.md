# TreeGit 2026.23.2

首个正式版，主要发布平台为 Windows x64。基于 SourceGit 2026.23，保留原有 Git 工作流并调整为 SourceTree 风格的操作布局。

## 主要功能

- 免安装、无需登录 TreeGit 账号，使用已有 Git for Windows；自带裁剪压缩后的 .NET 运行时。
- 提交、推拉、分支、标签、合并、变基、交互式变基、贮藏、冲突、补丁、文件历史、Blame、子模块、Worktree、Git Flow、LFS 和 Bisect。
- 独立 TreeGit 图标；提供 SourceTree 蓝白、墨青浅色、深色及跟随系统主题。
- 不透明仓库标签、选中项关闭 X、紧邻标签的新建按钮，以及可滚动的全部仓库下拉列表。
- 图谱主线置于左侧；当前分支默认保留完整历史，勾选远程分支时显示对应上游更新。本地分支头加粗，节点、仓库标签、拉取与推送按钮同步显示数量。
- 图谱顶部“未提交的更改”打开暂存、未暂存文件及差异；历史各列可拖动调整并按仓库保存。
- 搜索为右侧独立页面，保留五种搜索方式与结果详情；底部标签可直接退出搜索。
- 仓库设置采用远程仓库 / 高级两页，确认按钮固定在滚动区外，按屏幕可用区域限制窗口大小；原有完整配置位于其他配置。
- 每个仓库独立保存 HTTPS 账号，缺失或失效时自动提示认证；SSH 按远程选择 OpenSSH 密钥，HTTPS 使用 OpenSSL。
- MCP 默认完整读写，支持界面、仓库标签、查询与全部 Git 操作；支持显式只读模式。

## 安装与升级

1. 下载并完整解压 `TreeGit-Windows-x64.zip`，运行 `TreeGit/TreeGit.exe`。
2. 使用电脑已有的 Git for Windows，或在偏好设置中选择 Git；主包不重复捆绑 Git。
3. 升级时先关闭 TreeGit，保留原 `data/` 目录，再替换程序文件。已保存密码位于当前 Windows 用户的系统凭据库。
4. 校验包与 `SHA256SUMS.txt` 一致；`build-info.json` 记录版本、源代码提交及构建选项。

## MCP

工具 → MCP · AI 连接中复制配置。默认参数为 `["--mcp"]`；只读连接使用 `["--mcp", "--read-only"]`。详见 [MCP 使用说明](MCP.md)。
