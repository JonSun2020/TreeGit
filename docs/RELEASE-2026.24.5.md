# TreeGit 2026.24.5

- 提交与分支联动统一：搜索和详情显示相同的提交所属分支；对应本地分支及其跟踪远端同时使用深背景，其他包含分支使用浅背景。
- 保持左栏收起状态：相关分组收起时显示浅背景提示，展开后只突出具体分支；背景避开滚动条。分支列表中的所属分支及对应跟踪远端加粗。
- 搜索结果保留缓存，页面切回立即显示；仓库或远端引用变化后自动刷新。快速切换提交时不残留旧文件列表，文件状态与历史共用该仓库独立保存的分栏宽度。
- 文件状态与历史共用最后一次选择，进入搜索后再返回会恢复原提交、侧栏分支和变更文件；搜索单独保留自己的选择。
- 图谱配色随主题调整，优先拉开相邻分支的颜色差异；简体中文、繁体中文和英语可从“编辑 → 语言/Language”切换，悬停预览、离开恢复。
- 修正弹窗层级、表头、整行选择和窄窗口布局；独立二进制窗口不再重复打开自身。内置对比／合并默认使用 TreeGit，外部工具仅列出已实现适配的选项。
- 修正特殊文件名的外部合并、后台读取与子模块操作的索引锁争用，以及高缩放下切换页面后的滚动位置。
- 合并保存可处理 Windows 的短暂文件占用，保留文件与索引变化检查，失败时保留编辑结果。

保留完整 Git 工作流、内置二进制对比、可编辑三方合并和 MCP 读写控制。Windows x64 便携包包含 Git 与运行时，无需安装；现有用户可从“帮助 → 检查更新”升级。
