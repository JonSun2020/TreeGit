- 底部页面统一为“搜索／日志・历史／提交”。历史中选择未提交的更改，只显示文件和差异；提交页集中显示账号、分支、提交说明与提交操作。
- 提交历史说明最多显示当前分支可达的最近 10 条，包含合并进来的提交；保留多行内容，点选后插入光标位置。浮窗读取完成后直接显示，点击外部或再次点击按钮关闭。
- 绕过提交钩子、署名、立即推送直接放在提交区；未勾选文字及分隔槽使用凹陷效果。无暂存文件时禁用输入与提交，保留已有草稿。
- 提交与分支联动统一：搜索和详情显示相同的提交所属分支；对应本地分支及其跟踪远端同时使用深背景，其他包含分支使用浅背景。
- 保持左栏收起状态：相关分组收起时显示浅背景提示，展开后只突出具体分支；背景避开滚动条。分支下拉列表中的所属分支及对应跟踪远端加粗。
- 搜索结果保留缓存，页面切回立即显示；仓库或远端引用变化后自动刷新。快速切换提交时不残留旧文件列表，历史和提交页共用该仓库独立保存的文件栏宽度。
- 进入搜索后返回历史，恢复原提交、侧栏分支、变更文件与详情折叠状态；搜索单独保留自己的选择。
- 图谱配色随主题调整，优先拉开相邻分支的颜色差异；简体中文、繁体中文和英语可从“编辑 → 语言/Language”切换，悬停预览、离开恢复。
- 修正弹窗层级、表头、整行选择和窄窗口布局；独立二进制窗口不再重复打开自身。内置对比／合并默认使用 TreeGit，外部工具仅列出已实现适配的选项。
- 修正特殊文件名的外部合并、后台读取与子模块操作的索引锁争用，以及高缩放下切换页面后的滚动位置。
- 合并保存可处理 Windows 的短暂文件占用，保留文件与索引变化检查，失败时保留编辑结果。
- 首次启动按系统语言选择简体中文、繁体中文或英语，后续遵从用户配置；提交区与历史说明完整支持三种语言。

保留完整 Git 工作流、内置二进制对比、可编辑三方合并和 MCP 读写控制。Windows x64 便携包包含 Git 与运行时，无需安装；现有用户可从“帮助 → 检查更新”升级。
