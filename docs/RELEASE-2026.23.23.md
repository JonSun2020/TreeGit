# TreeGit 2026.23.23

- 单击左侧任一本地或远程分支，先切回“日志 / 历史”。保留当前分支或所有分支的图谱显示方式，不执行分支切换。
- 双击当前本地分支只返回历史页；双击其他本地分支，始终先显示“切换本地分支”确认框。有未提交修改时可选择保留、贮藏并恢复或丢弃修改。
- 双击远程分支显示“检出远程分支”。优先使用已跟踪该远程的本地分支；首次检出可指定本地名称，并正确建立跟踪关系。
- 远程检出保留已有本地提交。本地领先或与远程分叉时不重置历史；本地仅落后时可选择安全快进。名称冲突、已跟踪其他远程、其他工作树占用及尚无本地分支的情况均有对应处理。
- 取消确认不切换分支、不创建本地引用。远程检出的自动贮藏使用本次操作的记录，保留原有贮藏及未能自动恢复的修改。
- 保留搜索结果和“包含分支”列表的定位行为：返回历史并选中原提交，展开对应左栏分支，不执行分支切换。

安装包：`TreeGit-2026.23.23-Windows-x64.zip`。已有可在线更新的版本可通过“帮助 → 检查更新”升级，保留个人配置。
