# Interface languages

TreeGit supports Simplified Chinese (`zh_CN`), Traditional Chinese (`zh_TW`) and English (`en_US`).

All three dictionaries contain the same text keys. Run `python tests/localization_catalog.py` to check key coverage, format arguments and UI resource references.

Interface language is selected from the first item in the Edit menu. Hover previews a language; clicking saves it. Moving outside the language popup or closing the menu restores the saved choice when no language was selected.
