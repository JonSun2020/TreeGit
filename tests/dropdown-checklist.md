# TreeGit 下拉框自检清单

## 控件盘点

- 扫描实际编译的 XAML 和 C#，登记普通下拉框、紧凑下拉框、文件编码选择器和分支选择器。打开新页面或切换子页后重新盘点可见控件。
- 检查弹出选项与收起模板的数据来源。下拉框的实际选值、弹出列表选项和收起文字应当对应同一项。
- 检查自定义收起模板的文字资源、绑定和宽度测量。透明的测宽内容参与测量，只有当前选项的文字可见。

## 交互复查

| 页面 | 复查项目 |
| --- | --- |
| 搜索 | 简中、繁中、英文的五种搜索类型。点击当前项、切换到其它项、切回原项、重新打开和用键盘选择。检查收起文字及搜索结果。切换语言时检查当前项的文字，缩放后检查下拉框宽度。 |
| 日志和历史 | 分支范围、排序方式、提交变更的显示编码、对比上下文行数。选完立即切换提交页，确认应用继续响应。 |
| 提交 | 变更状态和排序、约定式提交类型。核对初始项、切换后的标题和重新打开后的状态。 |
| 仓库和偏好设置 | 默认远程、合并方式、凭据远程、日期、主题、字体、换行符和终端。测试空值占位项和长列表的末项。 |
| Git 操作 | 克隆、打开仓库、获取、拉取、推送、重置、合并、贮藏、应用补丁、标签推送、LFS、子模块、上游分支、Git Flow、自定义操作和忽略文件。根据业务状态使依赖选项可选。 |
| 文件和工具 | 历史文件编码、三方冲突编辑器的编码、统计分支、SSH 密钥类型和 AI 模型。使用匿名数据、临时仓库和隔离配置。 |

## 验收

- 在窗口中触发实际选择事件，等列表收起后同时核对选中索引和显示文字。搜索页还核对模型的搜索方式和返回的提交。
- 有固定小列表的控件逐项验证。动态长列表验证首项、切换项和滚动后的末项。
- 检查切换或取消操作前后的 HEAD、索引和工作文件。冲突场景核对原始冲突内容和未合并索引。
- 核对结果文件的通过项、操作记录和失败字段。验证构建与验收包使用相同源码和当前依赖，清理隔离程序和临时仓库后再同步。
